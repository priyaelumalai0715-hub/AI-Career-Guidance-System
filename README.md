🤖 AI Career Guidance System
📌 Project Overview
The AI Career Guidance System is a web-based application designed to help students identify suitable career paths based on their skills, interests, and strengths.

The system provides a simple platform where students can create their profile, log in, complete a skill assessment, and view career recommendations with a career match score.

🎯 Problem Statement
Many students find it difficult to choose the right career because they are unsure about their skills and career opportunities.

This project provides a simple digital solution that analyzes students' selected skills and provides suitable career guidance.

📄 Main Pages

2. Login Page

3. Dashboard
The dashboard displays:

Recommended Career

4. Student Profile

Email
Phone

5. Skill Assessment

SQL

6. Career Result
The result page displays a career match score and recommends a suitable career.

💾 Data Storage
This project uses Browser LocalStorage to temporarily store student information and selected skills.

Examples of stored data include:

Student email
Student name
Student phone number
Selected skills
No external database is required to run the current version of the project.

🚀 How to Run the Project
Step 1: Download or Clone the Project
Download the project from GitHub or extract the ZIP file.

Step 2: Open in VS Code
Open the AI Career guidance folder in Visual Studio Code.

Step 3: Install Live Server
Install the Live Server extension in VS Code.

Step 4: Open the Project
Open:

HTML/index.html
Step 5: Run with Live Server
Right-click index.html and select:

Open with Live Server

The application will open in your web browser.
